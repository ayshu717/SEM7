// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract StudentData {

    struct Student {
        uint rollNo;
        uint age;
        string name;
        uint marks;
    }

    Student[] public students;

    // Add Student
    function addStudent(
        uint _rollNo,
        uint _age,
        string memory _name,
        uint _marks
    ) public {
        students.push(Student(_rollNo, _age, _name, _marks));
    }

    // Get Student
    function getStudent(uint index)
        public
        view
        returns (uint, string memory, uint)
    {
        require(index < students.length, "Invalid ID");

        Student memory s = students[index];

        return (s.rollNo, s.name, s.marks);
    }

    // Get Student Count
    function getCount() public view returns (uint) {
        return students.length;
    }

    // Receive Ether
    receive() external payable {
        require(msg.value > 0, "Ether must be greater than 0");
    }

    // Fallback Function
    fallback() external payable {
        require(msg.value > 0, "Ether must be greater than 0");
    }
}


## 3. CODE EXPLANATION

### 1. SPDX License and Solidity Version

- `SPDX-License-Identifier: MIT` specifies the license of the source code.
- `pragma solidity ^0.8.20` specifies the compatible Solidity compiler version.

### 2. Contract Declaration

- `contract StudentData` creates a smart contract named StudentData.

### 3. Structure (Struct)

```solidity
struct Student {
    uint rollNo;
    uint age;
    string name;
    uint marks;
}
```

- A struct is a user-defined data type.
- It groups multiple variables of different data types into one unit.
- Here, it stores four student details:
  - `rollNo`: Student roll number.
  - `age`: Student age.
  - `name`: Student name.
  - `marks`: Student marks.

### 4. Dynamic Array

```solidity
Student[] public students;
```

- Creates a dynamic array of Student structures.
- It stores multiple student records.
- `public` automatically creates a getter function to access individual array elements.
- The array can grow whenever a new student is added.

### 5. Add Student Function

```solidity
function addStudent(
    uint _rollNo,
    uint _age,
    string memory _name,
    uint _marks
) public {
    students.push(Student(_rollNo, _age, _name, _marks));
}
```

- Used to add a new student's information.
- Takes four parameters: roll number, age, name and marks.
- `memory` temporarily stores the string during function execution.
- `students.push()` adds a new Student structure to the array.
- Every new student is stored at the next available index.

### 6. Get Student Function

```solidity
function getStudent(uint index)
    public
    view
    returns (uint, string memory, uint)
{
    require(index < students.length, "Invalid ID");

    Student memory s = students[index];

    return (s.rollNo, s.name, s.marks);
}
```

- Used to retrieve student details using the array index.
- `index` specifies the student's position in the array.
- `view` means the function reads data without modifying it.
- `require()` checks whether the index is valid.
- `Student memory s` temporarily stores the selected student's details.
- Returns roll number, name and marks.

**Important:** The original function does not return age, even though age is stored in the struct.

### 7. Get Student Count Function

```solidity
function getCount() public view returns (uint) {
    return students.length;
}
```

- Returns the total number of students stored in the array.
- `students.length` gives the current array size.
- `view` is used because the function only reads data.

### 8. Receive Function

```solidity
receive() external payable {
    require(msg.value > 0, "Ether must be greater than 0");
}
```

- `receive()` is a special Solidity function.
- It is automatically executed when the contract receives Ether with empty transaction data.
- `external` means it can be called from outside the contract.
- `payable` allows the contract to receive Ether.
- `msg.value` represents the amount of Ether sent in Wei.
- `require()` prevents receiving zero Ether.

### 9. Fallback Function

```solidity
fallback() external payable {
    require(msg.value > 0, "Ether must be greater than 0");
}
```

- `fallback()` is a special function executed when a call does not match any existing function.
- It can also execute when transaction data is empty if no receive function exists.
- Here, it is payable, so it can receive Ether.
- `require()` checks that the received Ether is greater than zero.

**Difference between receive() and fallback():**

| receive() | fallback() |
|---|---|
| Executes when calldata is empty | Executes when no function matches the calldata |
| Must be payable to receive Ether | Can be payable or non-payable |
| Used for plain Ether transfers | Used for unmatched calls and potentially Ether transfers |
| Has no parameters | Has no parameters |
